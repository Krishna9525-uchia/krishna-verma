## 2026-05-30 - [Adaptive Visibility for Action Buttons]
**Learning:** Using `md:opacity-0 group-hover:opacity-100 focus:opacity-100` allows action buttons (like "Copy") to remain visible by default on mobile devices while tucking them away on desktop until user interaction. This keeps the desktop UI clean without sacrificing mobile usability.
**Action:** Apply this pattern for secondary actions in list items or result cards to ensure touch-screen users don't miss functionality that relies on hover states.
