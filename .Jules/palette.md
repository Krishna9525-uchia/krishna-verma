## 2025-07-27 - [Micro-UX Clipboard Success Indicator in Multi-Result Views]
**Learning:** When adding clipboard copying to multiple inline result cards, displaying direct, localized visual feedback (e.g., transforming a CopyIcon to a CheckIcon on the specific clicked element) dramatically reduces user uncertainty. Using a dynamic state key such as `${res.label}-${index}` prevents state collision across multiple list items, and utilizing the CSS opacity transition classes allows the copy button to remain clean and hidden during regular viewing while preserving keyboard accessibility via focus styling.
**Action:** Always identify elements in a dynamic list using a combination of their unique text/labels and indexes, and implement localized visual feedback with standard 2-second timeout cleanups.
