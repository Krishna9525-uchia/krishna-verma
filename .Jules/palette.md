## 2025-05-14 - [Copy to Clipboard & Label Accessibility]
**Learning:** In utility-heavy applications like calculators, providing instant feedback (e.g., 'Copied!') for clipboard actions significantly reduces user uncertainty. Additionally, associating labels with inputs via `htmlFor` and `id` is a fundamental accessibility win that also improves mobile usability by expanding the hit target.
**Action:** Always ensure interactive elements provide immediate visual state changes upon success, and consistently use semantic relationships for form controls.
