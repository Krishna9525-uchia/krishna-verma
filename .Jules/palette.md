## 2025-07-25 - Dynamic Form Field Accessibility Mapping in React Loops
**Learning:** In highly dynamic applications (like CalcMaster Pro) where forms are generated dynamically from array definitions, a major accessibility risk is orphaned form labels. Since labels do not automatically bind to inputs/selects inside array maps, screen readers cannot convey the control's purpose. Associating them dynamically using the unique field property (`inp.name`) as both the `htmlFor` and `id` attribute, and adding `cursor-pointer` class to the labels, is an extremely high-leverage UX/accessibility pattern that scales across 40+ calculators while maintaining a tiny, clean, and bug-free code surface area.
**Action:** For any dynamically generated form field loops, always map unique definition-level identifiers to both `htmlFor` of the `<label>` and the `id` of the underlying inputs or selects, and styling labels with `cursor-pointer` to improve click targets.
