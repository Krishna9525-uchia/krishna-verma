## 2025-05-22 - [Clipboard Feedback Loop]
**Learning:** Providing a temporary success state (approx 2s) after clipboard actions reduces user uncertainty and eliminates the need for intrusive notifications. Dynamic ARIA labels (e.g., changing from "Copy" to "Copied!") ensure screen reader users receive immediate confirmation.
**Action:** Always implement a 2-second visual and accessibility feedback loop for copy-to-clipboard features in result-heavy interfaces.
