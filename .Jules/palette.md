## 2025-05-14 - Accessibility and Utility improvements
**Learning:** Even well-designed apps often miss basic accessibility features like linking labels to inputs and providing ARIA labels for icon-only buttons. Adding a "Copy to Clipboard" feature is a high-value, low-effort UX improvement for utility apps like calculators.
**Action:** Always check for label-input connections and missing aria-labels on interactive elements. Consider if users would want to copy output data.
