# Palette's Journal - UX & Accessibility Learnings

This journal documents critical UX and accessibility insights discovered while working on CalcMaster Pro.

## 2025-05-20 - Result Copy to Clipboard
**Learning:** Providing a temporary success state (approx 2s) after clipboard actions reduces user uncertainty and eliminates the need for intrusive notifications.
**Action:** Implement a toggle between 'Copy' and 'Check' icons with a 2-second timeout for all clipboard interactions.
